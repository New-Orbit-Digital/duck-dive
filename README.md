# Duck Dive

A whimsical score-attack side-scroller. You're a duck bobbing along the surface: tap to dive for fish, grab trash for a score multiplier, collect green seaweed to spend at the merchant duck, and dodge sticks, rocks and pufferfish.

This game is based on a duck that Phoebe thought of.

**Play:** https://justbost.com/duck-dive/

## Controls
- **Desktop:** press **D** (or click) to dive. **M** mutes.
- **Mobile:** tap anywhere to dive.

## Tuning
Every gameplay number (speed, spawn odds, points, merchant timing, shop prices) lives in [`tuning.js`](tuning.js). Edit, save, refresh.
